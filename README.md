# PAPER3NOTES — Paper 3: Introduction to Assessment & Basic Assessment Methods

Structured, faithful study notes for **Paper 3 — Introduction to Assessment and Basic
Assessment Methods** (Musculoskeletal Physiotherapy). Transcribed from the Paper 3
compilation, which is based chiefly on **David J. Magee, _Orthopedic Physical
Assessment_, 6th edition**, with companion material from Dutton (*Orthopedic
Examination, Evaluation & Intervention*), Gross et al. (*Musculoskeletal Examination*)
and others.

The material is organised into **24 modules** covering the full document — screening of
the spine and limbs, special tests, diagnostic imaging, fracture-assessment forms,
applied topics and outcome frameworks.

## Browse the notes

The notes are published as a self-contained HTML site. Open `docs/index.html` (or the
GitHub Pages site, once enabled) to browse every module as a single mobile-friendly page
with an on-page table of contents.

## Repository layout

```
notes/<module>.md     faithful source notes (Markdown), one file per module
docs/index.html       site index (GitHub Pages entry point)
docs/<module>.html    rendered, self-contained HTML page per module
```
